## §2 정의

### 2.1 용어

| 용어 | 뜻 |
|---|---|
| 화면(screen) | 양도박사의 입력 화면 하나. `screen_NN`(두 자리 순번)로 부른다. 순번은 신고 1건을 입력하는 자연 순서 |
| 항목(field) | 화면 안의 입력 칸 하나. `screen_NN.field_id`(영문 snake_case, 메인이 정함) |
| 케이스(case) | 입력값 묶음 + 양도박사 산출값 + 법령 기준 계산값. `C###` |
| C000 | 척추 케이스. 1주택자가 아닌 일반 납세자, 주택 1채, 보유 3년 이상 5년 미만, 거주 없음, 기본세율, 감면 없음, 예정신고. 분기(비과세·중과·감면·안분)가 하나도 걸리지 않는 가장 단순한 길 |
| 오라클 | 양도박사 산출값. 정답이 아니라 **비교 대상**. 정답은 법령 |
| 1바퀴 | C000이 §2.3의 산출물 6종을 모두 갖춘 상태 |

### 2.5 사람 / 에이전트 분업 (윈도우에서) — 탐색부터 에이전트

| 층 | 누가 | 하는 일 |

| 사람에게 남는 것 | 사람 | ProcMon 실행·CSV 내보내기(관리자 권한), 국세청 명세 다운로드, 모달·오류로 스크립트가 멈췄을 때 화면 확인, 금지 메뉴 판단 |

규칙:
- 금지 메뉴는 `drive/app.py`가 이름으로 차단한다(클릭 전에 메뉴 텍스트 대조). 목록은 `docs/env.md`에 둔다.
- 쓰기 동작(저장·생성)은 반드시 **데이터 폴더 백업 뒤** 하고, 케이스마다 복원한다. 백업 대상 폴더는 2단계 ProcMon 결과로 확정한다.
- 한글 값은 키 입력이 아니라 컨트롤 직접 쓰기(`set_edit_text`) 또는 클립보드 붙여넣기로 넣는다(IME 문제).
- 컨트롤이 노출되지 않는 화면(자체 그리기 그리드 등)은 좌표 클릭 + 화면 텍스트 읽기(Windows OCR)로 대체하고, 그래도 안 되면 Claude 데스크톱 앱 컴퓨터 사용(스크린샷·클릭)으로 에이전트가 직접 조작한다. 어느 길인지는 W1에서 정한다.
- 심한 경우 psr.exe는 사람이 1회 시연하는 보조 수단으로만 쓴다(계획 §2-1은 유지, 기본은 에이전트 탐색).
