  - 탭: 과세표준신고서(양도소득세), 과세표준신고서(지방소득세), 양도소득금액계산서, 건물기준시가계산서

## §2 정의

- **W2 자산 입력 화면 탐색**: 백업 → `2.자산등록` → `주택외건물(토지 포함)` 버튼 → 열린 화면(새 창이든 같은 창 안이든) 캡처·컨트롤 덤프 → 저장 없이 닫는다(`닫기`/`취소`, 모달은 처음 보는 것이면 중단) → 페이지 비교. 데이터 페이지가 바뀌면 "유형 버튼만 눌러도 쓴다"로 기록하고 메인이 판단한다.
- **단계 파일** `cases/basic/C000.asset.steps.yaml`(자산), `C000.buyer.steps.yaml`(양수인): 1단계와 같은 형식. 각각 리허설(취소로 끝남) → 실제 저장 → 확인 전용 실행 순서로 돌린다.
- **세액 읽기** `cases/basic/C000.read.steps.yaml`: `4.세액계산` → `세액재계산` 버튼(쓰기 여부는 페이지 비교로 기록) → 과세표준신고서(양도소득세) 탭의 항목 값을 읽는다(DataItem/Edit 값) → `양도소득금액계산서` 탭 값도 읽는다 → 캡처.
- **calc** `tools/calc/yangdo.py`: 조문 단위 함수(양도차익 §95①·§97, 장특 §95②, 기본공제 §103, 세율 §104①1·§55①, 지방소득세). 입력은 케이스 yaml `input`, 출력은 단계별 금액 dict와 근거 조문. 이번 경로(일반 부동산, 2년 이상 보유, 기본세율)만 구현하고, 그 밖의 분기는 `NotImplementedError`로 막는다.
- **대조 8항목**: 양도차익, 장기보유특별공제, 양도소득금액, 기본공제, 과세표준, 세율, 산출세액, 지방소득세(산출). 가산세·납부할세액 항목은 기록만 한다(신고구분·작성일에 따라 기한후 가산세가 자동 계산될 수 있음).
- **compare** `tools/compare.py cases/basic/C000.yaml`: `expected_baksa`(화면에서 읽은 값)와 calc 결과를 항목별로 비교해 `status: match|mismatch`를 쓴다. 불일치 원인 판정은 메인이 한다.

## §4 종료 조건 (실행 전에 고정)

1. Q4: 탐색기 실행에서 `2.자산등록` 화면 키가 `3.양수인등록` 화면 키와 다르다.
2. 자산 입력 폼 캡처와 컨트롤 덤프가 있다. 유형 버튼을 눌렀을 때의 페이지 비교 결과(데이터 페이지 변화 여부)가 구현 결과에 적혀 있다.
3. `tools/tests/test_calc_c000.py`가 통과한다. calc의 단계별 금액이 §0 법령 기대값(Fable 검산으로 확정한 상수)과 원 단위로 같다. 기대값을 바꿀 때는 조문 근거가 필요하다.
4. 자산·양수인 각각의 조건:
   - 리허설 종료 코드 0, 헤더·TIP만 변화
   - 실제 저장 종료 코드 0
   - 확인 전용 실행에서 자산 그리드 1건(1건 경로) 또는 2건(분기 경로)의 소재지·양도일자·양도가액이 입력값과 같다. 세율구분 열이 모두 기본세율(일반)이다.
   - 양수인 그리드 1행의 성명·양도자산·양수지분이 입력값과 같다.
   - 단계 파일 `modals`/`screens`에 없는 창이 뜨면 실패다.
5. 세액 계산 화면에서 대조 8항목을 읽었다. 세율은 "38" 또는 "38%"로 읽힌다. 메인이 캡처에서 8항목 전부를 직접 읽어 일치를 확인한다.
6. `cases/basic/C000.yaml`에 `input`(입력 전제 ①~⑦ 포함), `expected_baksa`(출처 캡처), `expected_law`(calc), `basis`(조문), `status`가 있다. 8항목이 전부 match면 `status: match`다. 아니면 `mismatch_note`에 항목별 원인 판정(양도박사 오류 / 숨은 분기 / 내 해석 오류)과 조문을 적는다.
7. fdb 비교:
   - 쓰기 실행: 바뀐 파일은 `neoTax.fdb` 하나(다른 fdb는 헤더·TIP만), 파일 `added`/`removed` 0
   - 읽기 실행(세액 읽기 포함): 헤더·TIP 외 변화가 있으면 기록하고 메인이 판정한다(`세액재계산`이 결과를 저장할 수 있음)
   - 단계 파일별 재실행 최대 3회, 복원 최대 1회. 넘으면 실패로 끝내고 사용자에게 보고한다

- 결함 번호: A / Q / U / u / F. 양도박사와 법령이 다르면 A가 아니라 케이스 `mismatch`로 기록한다(A는 우리 쪽 수치 오류).

## §5 열린 질문
