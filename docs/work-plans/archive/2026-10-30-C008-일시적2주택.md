## §1 확인한 사실

- 1세대1주택 창은 비과세 예/아니오와 거주기간 구간 11종만 받는다(C001 구현 결과 W1). 조정대상지역 칸은 미노출.
- calc는 `temporary_two_house: true`에서 NotImplementedError(`tools/calc/yangdo.py` `_check_scope`).

## §2 정의

- **calc 확장**: `temporary_two_house: true` + `new_house_acquisition_date` → 시행령 §155① 요건(종전 취득+1년 ≤ 신규 취득, 양도 ≤ 신규 취득+3년, 종전주택 §154① 요건) 충족 시 1세대1주택과 같이 비과세·고가주택 안분·장특 표2. 요건 미충족 → 비과세 아님(2주택 일반 경로 — 조정이면 C002/C003 분기). 결과 행 `one_house_special`("§155①" | None — Fable 검토 반영).
- **대조 10항목**: 양도차익 786,300,000 / 비과세 양도차익 629,040,000 / 과세대상 양도차익 157,260,000 / 장특 75,484,800 / 양도소득금액 81,775,200 / 기본공제 2,500,000 / 과세표준 79,275,200 / 세율 0.24 / 산출세액 13,266,048 / 지방소득세 1,326,604.
- **calc 테스트**: §0 "Fable 검토 반영" 행과 §4-1의 날짜(1년만 위반: 신규 2020-04-30·양도 2023-04-01, 3년만 위반: 신규 2021-06-01·양도 2025-08-20), 경계 "확인 필요", C000~C007 회귀.
