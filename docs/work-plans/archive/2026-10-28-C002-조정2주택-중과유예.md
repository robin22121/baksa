## §1 확인한 사실

- 자산 폼 "세율구분 및 과세특례"에 `1세대2주택`·`과세1주택`·`1세대3주택` 등 11종이 있다(`docs/rea/filing_cases.md` §1-E, 인벤토리 screen_07). 아파트 폼에서는 콤보로 보인다(캡처 `docs/screens/C001_09_recalculated.png` "일반과세" 콤보).
- 양도박사는 중과 유예 알림 문구와 상수 20220510~20260509를 갖는다(`docs/rea/diff_law.md` §2, `DM.fn_Alert_Jojung` 관찰). "양도소득세 중과 배제를 적용하시겠습니까?" 문구가 있다(filing_cases §1-E).
- 아파트 폼의 `cbJA`(조정대상지역) 체크는 덤프에만 있고 화면에는 보이지 않았다(C001 구현 결과 W1). 세율구분 선택에 따라 나타날 수 있다(가정).
- `tools/calc/yangdo.py`는 `one_house: false`인 주택에서 `NotImplementedError`를 낸다(`tools/calc/yangdo.py` `_check_scope`).

## §2 정의

- **calc 확장**: 주택 입력에 `house_count`(세대 주택 수), `adjusted_area_at_transfer`(양도 시점 조정대상지역) 추가. `one_house: false`이고 `house_count == 2`, 양도 시점 조정대상지역, 보유 2년 이상, 양도일 2022-05-10~2026-05-09 → 중과 배제(시행령 §167의10①12의2) → 기본세율(§104①1) + 장특 표1(§95② — 본문 괄호의 배제 대상 "§104⑦ 각 호 자산"이 아님). 조정대상지역이 아니면 중과 대상 아님 → 같은 결과. 결과 dict에 `surcharge_status`(`excluded_grace` / `not_adjusted`) 기록. 3주택 이상·유예기간 밖·보유 2년 미만은 계속 `NotImplementedError`.
- **대조 8항목**: 양도차익 390,500,000 / 장특 78,100,000 / 양도소득금액 312,400,000 / 기본공제 2,500,000 / 과세표준 309,900,000 / 세율 0.40 / 산출세액 98,020,000 / 지방소득세 9,802,000. 화면의 세율구분 열 이름(예: "1세대2주택(1-xx)")과 장특 코드도 적는다.
- **calc 테스트 경계 변형**: 양도일 2022-05-09(유예 전 — 중과, 범위 밖 NotImplementedError), 2022-05-10(유예 첫날 — 배제), 2026-05-09(유예 마지막 날 — 배제), 2026-05-10(NotImplementedError — "유예 연장 여부 미확인", 법령 확정 주장 아님), 비조정 양도(배제와 같은 결과, status `not_adjusted`), 3주택(NotImplementedError), 보유 1년 11개월(NotImplementedError — 단기세율 범위 밖).
- **단계 파일**: `cases/house/C002.{seller,asset,buyer,tax.read}.steps.yaml`(+ rehearsal). 실행 기록은 도구 규칙대로 `cases/basic/`.

## §4 종료 조건 (실행 전에 고정)

1. `python -m unittest discover -s tools/tests`가 C000·C001·C002(경계 변형 포함) 모두 통과. C002 상수는 §2 대조 8항목과 원 단위로 같다. 법령 기대값을 바꿔야 하면 §0 번복으로 기록한다.
2. 세율구분 콤보 항목 문자열 전부(개수 포함), `1세대2주택` 선택 후 뜬 창·문구(없으면 "없음"), 조정대상지역 칸 auto_id(없으면 "미노출")를 구현 결과에 기록했다.
3. 가상양도인3·자산 1건·양수인 1건 저장, 각 그리드 1행 확인. 쓰기 실행의 fdb 비교(neoTax 외 데이터 변화 0)가 구현 결과에 있다.
4. 메인이 세액 화면 캡처에서 §2 대조 8항목을 직접 읽었다.
5. 8항목 전부 원 단위 일치면 `cases/house/C002.yaml` `status: match`, 1개라도 다르면 `mismatch`와 항목별 원인 판정(양도박사 오류 / 숨은 분기 / 내 해석 오류)·조문. 중과 배제 선택지로 재계산한 경우 최종 결과가 status이고 첫 결과는 `mismatch_note`에 기록한다. W3 선택 항목(유예 종료 후 관찰)은 판정에서 제외한다.
6. 자산 리허설은 계산 앞에서 멈췄다(중복 자산 0). 단계 파일별 실행 최대 3회, 복원 최대 1회. 넘으면 멈추고 기록한다.

## §5 열린 질문

- 양도박사가 `1세대2주택` 선택 시 중과 배제 여부를 묻거나 자동 적용하지 않고 중과(+20%p)로 계산하면: mismatch로 두고 원인을 "양도박사 입력 누락/분기"로 판정한 뒤, 배제 선택지가 있으면 그것으로 다시 계산한다(단계 파일 재실행 상한 안에서).
- 자산 등록 화면이 세대의 다른 주택 정보를 요구하면: 가상 값(주택 B 2012-05-01 취득, 강남구 같은 주소)을 넣고 기록한다.
