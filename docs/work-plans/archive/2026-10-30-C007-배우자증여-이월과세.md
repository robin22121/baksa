## §1 확인한 사실

- 취득원인 창 `r3`·`r7`이 이월과세 선택지이고, 선택 뒤 `chDate`(증여자 취득일)·`chAmt`(증여세 상당액) 칸이 쓰인다(C006 W1, `docs/inventory/raw/C006_cause_window.json`; `chAmt`는 일반취득 때 비활성).
- calc는 상속(C006)을 지원하고 이월과세는 모른다(`tools/calc/yangdo.py`).

## §2 정의

- **calc 확장**: `acquisition_cause: 이월과세`, `donor_acquisition_date`, `donor_acquisition_price`, `gift_date`, `gift_value`, `gift_tax_attributable`(증여세 상당액). 기간 요건: 증여일 2023-01-01 이후 10년, 이전 5년(§97의2①, 부칙). 적용 시 취득가액 = 증여자 취득가액, 필요경비 += 증여세 상당액, 장특·세율 보유기간 증여자 취득일부터. §97의2②3 비교: 미적용 세액(취득가액 = 증여가액, 보유 증여일부터)보다 적용 세액이 적으면 미적용. 결과 행 `carryover: applied | not_applied_lower | out_of_period`. §97의2②1(사업인정 수용)·2(1세대1주택 비과세) 배제는 범위 밖.
- **대조 8항목**: 양도차익 496,000,000 / 장특 128,960,000 / 양도소득금액 367,040,000 / 기본공제 2,500,000 / 과세표준 364,540,000 / 세율 0.40 / 산출세액 119,876,000 / 지방소득세 11,987,600.
- **calc 테스트**: C007 상수(applied), 증여 2018-01-01·양도 2025-08-20(5년 초과, 2023 전 증여 → out_of_period, 증여가액 기준), 증여자 취득가액이 높아 적용 세액이 작은 경우(not_applied_lower), C000~C006 회귀.

## §4 종료 조건 (실행 전에 고정)

1. 테스트 전부 통과: (1) C007 상수·`carryover == "applied"` (2) out_of_period(증여 2018-01-01) + 경계 쌍(2022-12-31 증여 7년 후 → out_of_period, 2023-01-01 증여 7년 후 → applied) (3) not_applied_lower 산출세액 53,590,000 (4) 증여세 상당액≠0 필요경비 반영 (5) C000~C006 회귀.
2. `r3` 선택 뒤 칸 상태(`chDate`·`chAmt`·취득실가 의미)를 구현 결과와 `docs/inventory/raw/C007_*.json`에 기록하고, `docs/rea/diff_law.md` "이월과세 기간 문구" 행에 "2028-01 이후 실측 가능"을 적었다.
3. 가상양도인8·자산·양수인 각 1행, 계산서 취득일·거래원인이 입력과 같음(캡처), neoTax 외 데이터 변화 0.
4. 메인이 세액 화면 캡처 `docs/screens/C007_*_tax_*.png`에서 8항목을 읽어 값·파일명을 적었다.
