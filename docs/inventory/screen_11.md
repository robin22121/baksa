## 동작 메모

- 읽기 전용 칸이 있고(⑩), 값은 세부내역 그리드 행 합계로 들어간다. 다른 회색 칸도 같은 방식인지는 이 문서에서 확인하지 못했다.
- ⑥~⑧ 항목마다 세부내역 그리드가 따로 있고 클릭으로 전환되는 구조로 보인다(그리드 제목 문구가 항목별 — pil lbMsg 하나만 읽음).
- C000 필요경비는 두 번 이 창을 연다(토지 `btnS03`, 건물 `btnG03`). 건물 캡처 `C000_44_bldg_exp.png`: ⑩ 그리드 1행 `가상중개사무소 / 2025-06-30 / 1,800,000 / 현금영수증`을 넣자 ⑩·⑫·⑬이 모두 1,800,000으로 올라갔다.
- 이 창의 S로 시작하는 칸 이름이 취득실가 창(screen_10)과 겹친다(S11, S12 등). 서로 다른 항목이다.
