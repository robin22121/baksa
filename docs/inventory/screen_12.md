## 동작 메모

- 입력은 목록 위의 한 줄 입력 행에서 하고(등록 후 활성), 저장하면 아래 목록에 행이 생긴다(cap C000_09_buyer_filled).
- 리허설 2회 종료 코드 0, 헤더·TIP만 변화. 실제 저장 종료 코드 0, 그리드 1행 일치(C000-2단계 구현 결과 W4 양수인).
- 이 화면은 양도소득세 창에서 양도인이 선택된 상태에서만 열린다(좌측 단계 활성 조건 U1, screen_02).
- C000에서는 자산·양수인을 모두 저장한 뒤 세액 계산 화면을 읽었다(C000-2단계 구현 결과 W5). 양수인 없이 세액 계산 화면이 열리는지, 양수인이 세액에 영향을 주는지는 확인 못 함.
