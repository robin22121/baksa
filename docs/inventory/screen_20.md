- 기준정보(공제금액·공정시장가액비율)는 등록 전 빈 상태에서도 값이 이미 표시된다(cap 051). 값이 과세연도에 따라 바뀌는지는 확인 못 함. 탭 이름이 "년"과 "1년"으로 보인다(과세연도 탭으로 보이나 이름이 잘려 확정 못 함).
- 이 세목은 법인 납세자도 같은 화면에서 등록한다(납세자 구분 라디오).
