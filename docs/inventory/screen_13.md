## 동작 메모

- 이 화면은 C000에서 `세 액 재 계 산`을 누르지 않았는데도 값이 채워져 있었다. 자산내역등록의 `계산` 버튼이 계산 결과를 이 화면용으로 저장하기 때문으로 보인다(C000-2단계 구현 결과 W5, screen_07 동작 메모).
- 자산이 없는 양도인으로 열면 모든 칸이 0이다(cap 062).
- 세액 화면을 연 읽기 실행 뒤 `neoTax.fdb`의 data·pointer 페이지 변화가 기록됐다(C000-2단계 §4-7 판정 "읽기 실행(세액 읽기 포함)"). 화면을 여는 것만으로 DB가 바뀌었는지는 원인을 확정하지 못했다.
- `총 납부할 세액` 58,844,500은 18. 납부할세액 53,495,000 + 지방소득세 납부할세액 5,349,500과 같다(캡처 값의 산술 일치). 19. 분납 체크가 이 합계에 어떻게 반영되는지는 확인 못 함.
- 데모 버전에서는 인쇄·전자신고가 지원되지 않는다(제목줄 문구).
