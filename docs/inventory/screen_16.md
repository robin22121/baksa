## 동작 메모

- `등록`을 누르기 전에는 입력 칸이 회색 비활성으로 보인다(cap 033). 등록 후 어떤 팝업(양도소득세의 "양도구분 선택" 같은)이 뜨는지는 관찰하지 않았다.
- 상속인 그리드는 별도 입력 영역으로, 등록 시 상속인을 여러 명 입력하는 구조로 보인다(열 이름 근거).
- 신고구분 선택지가 양도소득세(예정·확정·수정·기한후)와 다르다(기한 내·수정·기한 후, cap 033).
