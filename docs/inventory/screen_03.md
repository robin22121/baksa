## 동작 메모

- 입력 순서: `등록` → "양도구분 선택" 창에서 구분 선택(screen_04) → 칸 입력 → `저장`. 저장 직후 `저장`·`취소`는 다시 비활성, 목록에 1행이 보인다(run114, cap C000_14).
- 저장한 양도인이 생겨야 좌측 `2.`~`4.` 단계가 활성화된다(U1). 같은 방식이 4세목 1단계에도 있다(screen_16~20 참고).
- 안내 패널(오른쪽 하단)이 포커스된 칸별 도움말을 보여 준다. 위 표의 안내 문구가 그 예다.
- 주소 칸은 클릭만으로 "주소 검색" 창이 뜬다. 관할세무서 콤보에 글자를 넣으면 표시는 되지만 세무서코드가 자동으로 안 채워졌다(Q5, 화면 안내문과 다름).
- 입력 한 건을 저장한 뒤 `neoTax.fdb`에서 데이터 페이지가 바뀌는 것을 확인했다(1단계 구현 결과). 화면 항목과 DB 컬럼 매핑은 `data/schema/mapping.csv` 영역이다.
