## 동작 메모

- 건물 탭 칸 중 auto_id는 버튼과 요약표만 덤프돼 있다(tab). 카드 칸의 auto_id는 확인 못 했다.
- 이 탭에 입력 없이도 C000은 기초 탭 입력만으로 계산이 끝났다(C000-2단계 구현 결과 W4). 건물 카드의 칸이 계산에서 어떻게 쓰이는지는 확인 못 함.
- FAQ(cap 016)는 증축 건물일 때 이 탭에서 건물을 추가해 거래원인을 증축으로 고르고, 주택이면 최초고시일·개별주택가격을 입력하라고 안내한다.
