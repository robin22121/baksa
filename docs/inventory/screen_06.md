## 동작 메모

- 유형 버튼 13개를 누르면 같은 자산내역등록 창(screen_07~09)이 열리는지 유형별로 다른 폼이 열리는지는 `주택외건물(토지 포함)` 하나만 확인했다. 폼 구성(탭 이름, 칸)은 해당 유형 기준이다.
- 결함 U2: 유형 버튼을 누르고 확인창에 `아니오`로 폼이 열리는 순간 `neoTax.fdb`에 레코드가 생긴다(저장 전). 저장 없이 닫으면 목록은 0건이나 data 페이지 변화는 남는다.
- 결함 U4: 자산내역등록의 `계산` 버튼이 저장까지 해서(screen_07 동작 메모) 이 목록에 중복 자산이 생긴 적이 있고, `자산 삭제`로 정리했다.
- 목록 `양도가액` 셀 값은 DataItem으로 읽으면 200000000인데 화면 표시는 800,000,000이다(C000-2단계 구현 결과). 원인은 확인 못 함.
- 이 화면에서 `4. 세 액 계 산`이 활성화되려면 자산이 1건 이상 있어야 하는지는 확인 못 함(C000에서는 자산·양수인 저장 뒤 열림).
