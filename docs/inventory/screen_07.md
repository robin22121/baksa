## 동작 메모

- 탭을 "아는 경우"로 바꾸면 양도일자·취득일자·면적·세율구분·취득가액 종류 등 칸이 한 화면에 쏟아져 나온다(cap asset_try_05). 오른쪽 안내 패널에는 선택지 설명이 길게 뜬다(예: "취득실가를 알고 안분하는 경우"는 신축·미분양 감면, 상가겸용주택 안분, 건물부수토지 기준면적 초과, 매매사례가액·감정가액 취득 시 선택하라는 안내와 시행령 제159조① '23.2.28 이후 양도분 인용).
- 양도가액을 입력하면 Tab 이동 연쇄로 취득실가·필요경비 하위 창이 자동으로 열린다(C000-2단계 구현 결과 W4 1차). 단계 파일은 그 창을 닫고 `수정` 버튼(btnS02·btnG02·btnS03·btnG03)으로 다시 연다.
- `계산` 버튼이 저장까지 한다(U4). 소재지가 비어 있으면 모달 "소재지를 입력하십시오."가 뜨고, 확인을 누르면 주소 검색 창이 자동으로 열린다(U3).
- `저장`을 누르면 폼이 스스로 닫혀 자산 목록(screen_06)으로 돌아간다(F6).
- 폼이 열리는 순간 DB에 레코드가 생긴다(U2, screen_06 동작 메모).
- 결과 요약표의 토지·건물 값은 calc와 원 단위 일치(C000-2단계 구현 결과 W4).
