- 화면 캡처 번호: `docs/screens/C000_10_new_screen.png`(양도인 주소에서 열린 창), `.scratch/addr_res.png`(검색 결과가 보이는 창, 자산 소재지 쪽 단계 `.scratch/addr_probe.steps.yaml`에서 `CC02` 클릭으로 열림)

## 동작 메모

- 주소는 이 창으로만 넣을 수 있다. 호출 화면의 주소 칸에는 직접 타이핑되지 않는다(1단계 구현 결과 "관찰").
- 양도인 주소는 비워도 저장된다. 자산 소재지는 비우면 `계산`이 막힌다(모달, 결함 U3. screen_07 동작 메모).
- 주소 검색 결과의 건물명·고유번호가 자산 소재지 문자열에 `(성산동, 마포구청, 370)`처럼 붙는다(cap C000_57_calculated).
