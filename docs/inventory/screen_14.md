## 동작 메모

- 안내문대로 각 금액이 수정 가능한 칸으로 만들어져 있다(위 주황 안내). 수정 후 되돌리는 방법은 "자산 수정에서 다시 저장"뿐이라고 화면이 말한다.
- 화면의 합계 양도가액 800,000,000, 취득가액 575,300,000, 양도차익 217,500,000, 장기보유특별공제 21,750,000, 양도소득금액 195,750,000은 C000 정답과 일치했다(C000-2단계 구현 결과 W5, 메인이 캡처에서 직접 확인).
- 자산이 토지·건물 2건으로 쪼개져 2열로 나온다. 자산 목록(screen_06)에는 1행(기타건물)만 있다.
- 마지막 탭 `건물기준시가계산서`와 둘째 탭 `과세표준신고서(지방소득세)`는 문서화하지 못했다.
