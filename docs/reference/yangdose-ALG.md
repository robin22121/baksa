### ALG-2. 1세대 1주택 비과세 판단 알고리즘

```
입력: 취득일, 양도일, 취득 시 조정대상지역 여부, 보유기간, 거주기간

[Step 1] 1세대 판정
  - 1세대 = 거주자 + 배우자(별거 포함) + 동일 주소 직계존비속
  - 30세 미만 미혼 자녀 → 부모 세대에 포함
  - 30세 이상 또는 혼인한 자녀 → 별도 세대
  → 서비스에서는 사용자 자기 판단 (1세대 여부 질문)

[Step 2] 보유기간 확인
  - 보유기간 = 취득일 ~ 양도일 (역년 기준)
  - 2년 미만 보유 → 비과세 불가 → 과세 진행

[Step 3] 거주 요건 확인
  IF 취득일 < 2017-08-03:
    → 거주 요건 없음. 보유 2년이면 비과세.
  ELIF 취득 시 조정대상지역:
    → 보유 2년 + 거주 2년 필요
    → 거주기간 < 2년이면 비과세 불가 → 과세 진행
  ELSE (비조정지역):
    → 보유 2년이면 비과세

[Step 4] 비과세 판정
  - 위 요건 충족 → 비과세 대상
  - 양도가액 > 12억원 → 고가주택 안분 과세 (ALG-4)
  - 양도가액 ≤ 12억원 → 완전 비과세 (세금 = 0)
```

**판정 시점:** 양도일(잔금 수령일 또는 등기이전일 중 빠른 날) 기준

### ALG-3. 일시적 2주택 비과세 특례 판단

비과세 요건 충족 시 **1주택과 동일하게** 고가주택 안분, 장특공제 적용.

#### 사유 1: 신규주택 취득 (소득세법 시행령 §155①)

```
요건:
  ① 종전주택 취득 후 1년 이상 경과 후 신규주택 취득
  ② 신규주택 취득일로부터 3년 이내 종전주택 양도
  ③ 종전주택이 1세대 1주택 비과세 요건 충족 (보유 2년, 거주 요건)
결과: 종전주택 양도 시 1주택 비과세 적용
```

#### 사유 2: 상속 (소득세법 시행령 §155②)

```
요건:
  ① 상속으로 인해 2주택이 된 경우
  ② 일반주택(비상속)을 양도하는 경우
결과: 상속주택은 주택 수에서 제외 → 일반주택 양도 시 1주택 비과세
참고: 상속주택을 양도하면 → 일반 과세
```

#### 사유 3: 혼인합가 (소득세법 시행령 §155⑤)

```
요건:
  ① 혼인으로 인해 2주택이 된 경우
  ② 혼인일로부터 5년 이내 양도
결과: 1주택 비과세 적용
```

#### 사유 4: 동거봉양 합가 (소득세법 시행령 §155⑥)

```
요건:
  ① 60세 이상 직계존속과 합가하여 2주택이 된 경우
  ② 합가일로부터 10년 이내 양도
결과: 1주택 비과세 적용
```

#### 사유 5: 농어촌/고향주택 (소득세법 시행령 §155⑦⑧)

```
요건:
  ① 수도권 밖·광역시 밖·읍·면 지역 소재 주택
  ② 취득 시 기준시가 3억원(수도권 밖 6억원) 이하
  ③ 일반주택을 양도하는 경우
결과: 농어촌/고향주택은 주택 수에서 제외 → 1주택 비과세
```

#### 사유 6: 장기임대 거주주택 (소득세법 시행령 §155⑳)

```
요건:
  ① 장기임대등록 주택 보유 + 거주주택 보유 (2주택)
  ② 거주주택을 양도하는 경우
  ③ 거주주택이 1주택 비과세 요건 충족
결과: 거주주택 양도 시 1주택 비과세
```

### ALG-4. 고가주택 안분 과세 (양도가 > 12억원)

```
전제: 1주택 비과세 대상이지만 양도가액이 12억원 초과

[Step 1] 양도차익 산출
  양도차익 = 양도가액 - 취득가액 - 필요경비
  (필요경비는 안분하지 않음. 양도차익을 먼저 전액 산출)

[Step 2] 과세 비율 산출
  과세비율 = (양도가액 - 12억원) / 양도가액

[Step 3] 과세 양도차익
  과세 양도차익 = 양도차익 × 과세비율

[Step 4] 이후 계산
  과세 양도차익에 대해 장특공제(ALG-5) → 기본공제 → 세율 적용
  (1주택 장특공제율 적용)
```

**기준:** 양도가액 기준 (취득가 아님). 12억원 기준은 2021.12.8 이후 양도분부터.

### ALG-5. 장기보유특별공제

#### 5-A. 1세대 1주택 (비과세 대상 고가주택 포함)

```
조건: 보유 3년 이상

보유기간 공제율 (연 4%, 최대 40%):
  3년: 12%  |  4년: 16%  |  5년: 20%  |  6년: 24%  |  7년: 28%
  8년: 32%  |  9년: 36%  |  10년 이상: 40%

거주기간 공제율 (연 4%, 최대 40%):
  2년: 8%   |  3년: 12%  |  4년: 16%  |  5년: 20%  |  6년: 24%
  7년: 28%  |  8년: 32%  |  9년: 36%  |  10년 이상: 40%

총 공제율 = 보유 공제율 + 거주 공제율 (최대 80%)
공제액 = 과세 양도차익 × 총 공제율
```

#### 5-B. 일반 (2주택 과세 등)

```
조건: 보유 3년 이상

보유기간 공제율 (연 2%, 최대 30%):
  3년: 6%   |  4년: 8%   |  5년: 10%  |  6년: 12%  |  7년: 14%
  8년: 16%  |  9년: 18%  |  10년: 20% |  11년: 22% |  12년: 24%
  13년: 26% |  14년: 28% |  15년 이상: 30%

거주 공제: 없음
공제액 = 양도차익 × 보유 공제율
```

#### 5-C. 장특공제 적용 불가 케이스

```
- 보유기간 3년 미만: 공제 0%
- 다주택 중과 적용 시 (2026.5.10 이후): 장특공제 배제
- 중과 유예 기간 (~ 2026.5.9): 일반 장특공제(5-B) 적용 가능
```

**보유기간 계산:** 취득일 ~ 양도일, 역년 기준 (만 N년)
**거주기간:** 주민등록 기준 실거주 기간, 사용자 직접 입력

```
    - 토지거래허가제도상 매수자의 실거주 의무 유예
      → 현행 임대차계약의 최초 계약 종료일까지 (최장 2028.2.11)
    - 주택담보대출 전입신고의무 유예
      → "대출실행일+6개월" 또는 "임대차계약종료일+1개월" 중 늦은 시점까지
    - 단, 매도인이 다주택자 + 매수인이 무주택자(토허 신청일/대출 신청일 기준)인 경우만
    - 매도인이 1주택자인 경우에는 적용 안 됨
  → 이 서비스에서는 직접 판별하지 않고, 해당 사항 안내만 제공

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
[종합 판별 플로우] 2주택 과세 시 중과 적용 여부
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  입력: 양도일, 주소(조정대상지역 여부), 보유기간,
        매매계약일(선택), 토지거래허가 신청일(선택)

  IF 주소가 조정대상지역이 아님:
    → 중과 없음. 기본세율 적용.

  ELIF 양도일 ≤ 2026-05-09 AND 보유기간 ≥ 2년:
    → 한시 유예 적용. 기본세율 + 일반 장특공제.

  ELIF 양도일 > 2026-05-09:
    지역 = 기존4구 또는 신규지정 판별
    허용기간 = 기존4구이면 4개월, 신규지정이면 6개월
    최종기한 = 기존4구이면 2026-09-09, 신규지정이면 2026-11-09

    ── 경로 ⓐ: 매매계약 체결분 ──
    IF 매매계약일 ≤ 2026-05-09
       AND 양도일 ≤ 매매계약일 + 허용기간:
      → 보완 조치 적용 → 중과 안 함

    ── 경로 ⓑ: 토지거래허가 신청분 ──
    ELIF 토허신청일 ≤ 2026-05-09
         AND 양도일 ≤ 매매계약일 + 허용기간
         AND 양도일 ≤ 최종기한:
      → 보완 조치 적용 → 중과 안 함

    ELSE:
      → 중과 적용.
      → 세율: 기본세율 + 20%p (2주택 기준)
      → 장특공제: 배제 (0%)

  ※ 서비스 구현 시:
    - 매매계약일, 토허신청일은 선택 입력으로 받음
    - 미입력 시 보완 조치 판별 불가 → "중과 적용 가능성이 있습니다. 세무사 상담 권장" 안내
    - 이 서비스는 1~2주택 대상이므로 중과세율은 +20%p만 적용
    - 토지거래허가 관련 실거주 의무 유예는 안내만 제공 (자동 판별 안 함)
```

```
총 납부세액 = 산출세액 + 지방소득세
```

### ALG-10. 전체 세액 계산 플로우

```
[입력]
  양도가액, 취득가액, 필요경비(항목별),
  취득일, 양도일,
  주택 수(1주택/2주택), 거주기간,
  취득 시 조정대상지역 여부,
  (2주택 시) 일시적 2주택 사유 및 요건 충족 여부

[Step 1] 양도차익
  양도차익 = 양도가액 - 취득가액 - 필요경비
  IF 양도차익 ≤ 0 → 양도차손, 세금 = 0, 종료

[Step 2] 비과세 판정 (ALG-2, ALG-3)
  IF 1주택 비과세 또는 일시적 2주택 비과세 특례:
    IF 양도가액 ≤ 12억:
      → 완전 비과세, 세금 = 0, 종료
    ELSE:
      → 고가주택 안분 (ALG-4)
      → 과세 양도차익 = 양도차익 × (양도가 - 12억) / 양도가

[Step 3] 보유기간 계산 (역년 기준)
  보유기간 = calcHoldingYears(취득일, 양도일)

[Step 4] 장기보유특별공제 (ALG-5)
  IF 비과세 대상 고가주택:
    → 1주택 장특공제 (보유+거주, 최대 80%)
  ELIF 2주택 과세 + 중과 유예 기간:
    → 일반 장특공제 (보유만, 최대 30%)
  ELIF 2주택 과세 + 중과 적용:
    → 장특공제 배제 (0%)
  공제 후 양도소득금액 = (과세)양도차익 - 장특공제액

[Step 5] 기본공제
  과세표준 = max(0, 양도소득금액 - 250만원)

[Step 6] 세율 적용 (ALG-6)
  IF 보유기간 < 1년:
    산출세액 = 과세표준 × 70%
  ELIF 보유기간 < 2년:
    산출세액 = 과세표준 × 60%
  ELIF 2주택 + 중과 적용 (유예 종료 후):
    산출세액 = 과세표준 × (기본세율 + 20%p) - 누진공제
  ELSE:
    산출세액 = 과세표준 × 기본세율 - 누진공제

[Step 7] 지방소득세
  지방소득세 = 산출세액 × 10%

[Step 8] 총 납부세액
  총 납부세액 = 산출세액 + 지방소득세

[출력]
  양도차익, 과세 양도차익, 장특공제액, 양도소득금액,
  기본공제, 과세표준, 적용세율, 산출세액, 지방소득세, 총 납부세액,
  비과세 여부, 양도차손 여부, 고가주택 안분 정보
```

### ALG-11. 공동명의 계산

```
[입력] 공동명의자 목록 (이름, 주민번호, 지분율)

각 명의자별 독립 계산:
  FOR EACH 명의자 IN 공동명의자:
    명의자.양도가액 = 전체 양도가액 × 명의자.지분율
    명의자.취득가액 = 전체 취득가액 × 명의자.지분율
    명의자.필요경비 = 전체 필요경비 × 명의자.지분율
    → ALG-10 전체 플로우 개별 실행
    → 각자 기본공제 250만원 적용
    
총 납부세액 = SUM(각 명의자.총 납부세액)
```
