# 양도박사 양도소득세 계산 흐름 (정적 분석 B 단위)

- 대상: `C:\Neoic\Tax2019\YDdoctor.exe` (SHA-256 a528bfb2…c6c9, MVID 52da1e5a-b892-417c-a02c-458e921388e9). 실행하지 않음.
- 목적: 계산 순서·분기·상수의 이해. 클론이 아님. 코드·CIL은 싣지 않고 식별자와 상수만 적는다.
- 표기: 관찰 = REA 메타데이터(호출 간선·필드 접근·ldstr·상수 앵커)에서 직접 확인. 추정 = 위 근거로 해석한 것. 미확인 = 근거 없음.
- 한글 라벨 일부는 화면 문구(ldstr)에서 읽었다. 변수 이름(CC04 등)의 의미는 같은 화면 라벨 문자열과 JASAN100 쿼리 별칭에서 맞춰 추정했다.

## 0. 먼저 알아둘 것 (엔진 위치)

1. 계산 엔진은 별도 DLL이 아니다. 네이티브 호출은 창 관리·QR(NTS.dll)·암호/해시·SMS뿐이다(Evidence E1). 계산은 `YDdoctor.exe` 내부 관리 코드와 Firebird 테이블(JASAN100, MEN100)을 오간다.
2. `Cal100gr_2025`는 계산기가 아니라 결과·과세표준신고서 성격의 화면이다. 호출 대상은 데이터셋·문자열 목록·출력(`GRReport`)이며 세율 상수가 없다(E2). 이름의 연도 접미사(`_2018`~`_2026`)는 신고서 서식 연도 쪽이다.
3. 실제 계산은 아래 네 덩어리로 나뉜다.

## 2. 단계별 상세

### 2.1 양도가액·취득가액·필요경비 → 양도차익 (TIncome.Exec)

- 근거: `TIncome.Exec` 안의 계산근거 로그 문구와 호출 순서(E8).
- 관찰한 산식 문구(화면 계산근거에 그대로 출력됨):
  - 양도차익 = 양도가액 − 취득가액 − 필요경비 (토지초과이득세를 이미 낸 경우 이를 추가로 뺌).
  - 필요경비 개산공제: 취득가액 × 0.01, 취득가액 × 0.03, 취득일 기준시가 × 0.003, 취득일 기준시가 × 0.03 (어느 자산에 어느 율인지는 분기 해석 전, 추정: 환산취득가액·미등기 등 경우의 구분).
  - 환산취득가액(양도 기준시가 비례) 분모·분자 문구, 신축건물 환산취득가액의 5% 가산 문구(`Cal100` 쪽 가산세 로그에서도 확인).
  - 부담부증여, 이월과세(증여자 취득가액·증여세 상당액 가산), 지분율 곱 등 별도 산식 문구가 다수 있음. C000·C001 경로에는 해당 없음.
- 분기 조건: 자산 종류 문자열(토지·건물·아파트·상업용건물·일반주택·재개발아파트·부동산권리·입주권·골프회원권·기타자산)과 구분값 1/2(전체/지분 구분으로 추정)로 갈린다.
- 상수 외에 Trunc(절사)와 Round가 단계마다 쓰인다. 원 단위 절사가 기본이다.

### 2.2 비과세·고가주택 안분 (12억 기준)

- 고가주택 기준금액 함수: `Common.DM.GetHighPrice` (E4).
  - 양도일 20211208 이후: 1,200,000,000원
  - 20081007 이후 ~ 20211207: 900,000,000원
  - 그 이전: 600,000,000원
- 안분식 문구(TIncome.Exec): 고가주택 양도차익 = 양도차익 × (양도실가 − 기준금액) ÷ 양도실가. 화면 문구에 "고가주택분"이라는 접두가 붙어 양도소득금액이 따로 출력된다.
- 비과세(1세대1주택 등) 요건 판정은 `Jasan.fn_Ju_Check*`, `ChkInfo*`, `HChkInfo*`, `HighInfo*`, `CityInfo_JU2022` 쪽으로 보이나 이번 범위에서 내부를 열지 못했다(미확인). `DM.fn_Alert_Jojung`은 2022-05-10~2026-05-09 양도 시 다주택 중과를 적용하지 않고 일반과세로 할지 묻는 알림이다(상수 20220510, 20260509).
- 비과세 처리 후 "비과세 양도차익(이연)"과 "과세대상 양도차익"이 별도 칼럼으로 저장된다(Cal100 화면 라벨).

### 2.3 장기보유특별공제 (TIncome.CalcLongRate → CommonFunction.GetRate)

- `CalcLongRate`는 `CommonFunction.GetRate`를 부르고, 결과를 "▣ 장기보유특별공제 = 양도차익 x 율" 형식으로 로그에 남긴다. 장특 = 양도차익 × 율(고가주택은 안분된 과세분 양도차익 기준으로 추정).
- `GetRate`는 보유연수·거주연수·표 구분, 취득일/양도일을 받고, 양도일 20250101·20210101(연도 2021 비교)·20130215 등의 분기를 가진다(E11). 비율은 정적 배열(필드 RVA 데이터)에서 읽는다. 배열 내용은 PE 파일에서 직접 읽었다(아래 표). 어느 배열이 어느 분기에서 쓰이는지는 CIL 분기 해석을 하지 않아 "추정"이다.

### 2.4 양도소득금액

- 양도소득금액 = 양도차익 − 장기보유특별공제 (화면 문구). 감면소득금액 = 양도소득금액 × 감면비율(조정감면소득금액은 별도 문구).
- 저장: JASAN100의 CC20(양도차익), CC21(장특), CC22(양도소득금액), CC23(감면소득금액)에 대응(Cal100 쿼리 별칭과 UPDATE 문에서 확인, E3).

### 2.5 세율구분 코드 (GetTaxRateCode / GetTaxRateSort)

- 코드는 "1-10"처럼 구분-번호 형태. 관찰된 의미(문구와 분기에서 추정):
  - 1-10 누진세율(일반), 1-11 누진세율 + 비사업용토지 가산(10%p), 1-12 투기지역, 1-15 2년 미만(주택 외 40%), 1-16 2년 미만(조정), 1-20/1-2O/1-21/1-22 1년 미만, 1-25/1-26 계열 비사업용·누진 가산, 1-29/2-29/3-29 조정대상지역 비교, 1-30 미등기(70%), 2-10/3-10 주택 중과(2주택/3주택) 계열, 1-35/36/51~58/71/73/82~89 감면·임대·단기 관련 보조 코드, 1-4x/1-6x 주식 계열.
  - `GetTaxRateSort`는 코드를 36/40/50/60/70 같은 숫자 그룹으로 매핑(예: 1-10, 1-51, 1-52, 1-55, 1-56 → 36; 1-15, 1-35 → 40; 1-20, 1-21 → 50; 1-25, 1-26 → 60; 1-30 → 70). 이 숫자는 장특 로그의 "세율구분" 분기와 짝으로 보임(추정).
- 연도 분기: 양도연도 2018 이전/이후에 따라 코드 체계가 바뀐다(Cal100 문구 "2018.1.1일부터 세율코드가 변경 및 세분화").

### 2.6 세액계산 화면 진입 (Cal100.btnCalAll_Click / JasanTaxProc)

- 쿼리(관찰): JASAN100에서 해당 양도인(MENID)·계산반영(CALC=1)·과세구분(CCGU=1 또는 부담부증여)·양도소득금액 또는 양도가액이 0이 아닌 자산을 읽는다. 별칭 목록에 기신고 여부, 양도차익, 장기보유특별공제, 양도소득금액, 감면코드, 감면율, 한도, 농어촌 구분 등이 있다(E3).
- 검증: 양도연도가 서로 다른 자산이 섞이면 중단 메시지. 세율종류 8가지 이상 미지원(문구).
- 편집제한/편집허용: 계산 후 자산을 잠그고 재계산을 막는 상태 플래그.
- 정렬: 과세 구분, 양도일자, 세율C, 자경, 감면율2, 양도소득금액 내림차순 등(동일 날짜 여러 자산의 기본공제 배분 순서).

### 2.7 세율구분별 슬롯 → 기본공제 → 과세표준 (Cal100.CalResult)

- 7개 세율 슬롯(CC03_1~CC03_7): 슬롯마다 세율구분(CC03), 양도소득금액(CC04), 기신고분(CC05), 기본공제(CC06), 과세표준(CC07), 세율(CC08), 산출세액(CC09), 감면(CC10), 공제·가산(CC11~CC14), 합계(CC15)를 갖고 마지막에 슬롯 합을 낸다. 슬롯 번호 접미(_1.._7)와 합계 칼럼이 반복해 관찰됨(E3).
- 기본공제: 상수 2,500,000(연 1회 공제, 소득세법 §103). 값이 이미 공제된 금액(OldBase, 기신고 기본공제)과 비교해 남은 한도만 쓴다. 동일 날짜에 2개 이상 자산을 양도한 경우 납세자에게 유리한 쪽 세율구분 자산에 먼저 배분하고 "양도소득기본공제 재배분" 로그를 남긴다(문구에 예규 번호 재일 46014-1685, 1997.7.11 인용; `Cal100.fn_RateConfirm`).
- 과세표준 = 양도소득금액(+합산분) − 기본공제 − 감면대상 제외분(추정). Trunc 적용.

### 2.8 세율·산출세액 (TMenCC.Cal_TaxRate → _2018/_2019, CommonVar.basicRate)

- `Cal_TaxRate`는 양도연도와 자산종류("부동산")를 보고 `Cal_TaxRate_2019`(2019 이후) 또는 `_2018`을 호출한다. 그 외에는 안에 연도별(2001~2018) 구세율 분기를 직접 가진다.
- 누진세율은 `CommonVar.basicRate`(연도별 표)에서 가져온다. `compareRate*`는 단기·중과 대비 비교세액 계산 보조.
- 비교과세: 산출세액 = 아래 후보 중 큰 값(문구 "① 과 ② 중 큰 금액을 적용"). 후보는 누진세율 적용분(1-10/1-11), 1년미만, 2년미만, 비사업용토지, 1세대2주택·3주택(조정대상지역), 미등기이다. 통합(합산) 일반세율 산출세액과 분리합계 산출세액을 비교해 큰 쪽(<7> 문구, `Cal100m_2020`) .

### 2.9 산출세액 → 감면세액

- 감면: 감면코드(CC24_CODE)·감면율(CC24_JISU)·한도(CC24_HANDO)·농어촌 구분을 JASAN100에서 읽고 `TMenCC.fn_GamAmt`, `fn_GamRateAmt`, `fn_GetGamAmt`가 감면소득금액 기준으로 감면세액을 만든다.
- 상수: 100,000,000, 200,000,000(연/5년 한도, 조특법 §133으로 보임, 문구에 "감면받을 세액이 N억원을 초과하는 경우 초과부분 감면하지 않음" 있음), 감면율 조합 코드 15/20/25/30/40/50(20254050, 15203040, 1520 등), 100(퍼센트 환산).
- 감면 후 세액은 `fn_GetTaxAmt`가 세율구분별 비교 표(과세표준·산출세액·감면소득금액한도·감면소득세액한도 열)로 합친다.
- `Cal_TaxRate_2019` 안의 날짜·금액 상수(2020, 2021, 2023, 2025; 242,500,000; 249,250,000; 1,308,000,000; 1,318,800,000; 1,770,000,000; 102,933,333; 99,333,333; 20200214)는 용도를 해석하지 못했다(미확인). 감면 한도 또는 비교 임계값으로 추정.

### 2.10 가산세

- `DM.DLLAddTax`, `DLLAddTax0701`, `DLLAddTax200101`, `DLLAddTaxII`가 가산세 팝업(`neoAddTax*`)을 연다. 이름의 숫자는 법령 시행 시점(2007-01, 2001-01 등) 구분으로 추정.
- `neoAddTaxII` 관찰 상수: 20%, 40%, 10%, 50%(감면), 3%, 일수·월수 계산(MonthCheck 12·61·24 등). 화면 문구에 "납부불성실 일 3/10000"이 있음(Cal100). 어느 기간에 어느 이율인지는 해석하지 못했다(미확인).
- 신축·증축건물 5% 가산세: "건물 취득가액 × 0.05" 문구와 별도 라인(소득세법 §114의2로 추정).

### 2.11 분납

- 상수 10,000,000, 20,000,000(국세 분납: 1천만원 초과 시 2천만원 이하는 초과분, 2천만원 초과는 절반) 및 5,000,000, 10,000,000(지방소득세 분납)이 CalResult에서 관찰된다(문구 "분납할 세액(2개월 이내)").

### 2.12 지방소득세 (CalResult 하단, Cal100 문구)

- 산출 = 산출세액 × 10%(Trunc). 세율구분별 로그 문구에서 미등기 7%, 1년 미만 5%, 1년 미만 주택 계열 5%, 2년 미만 4%, 누진세율 구간(…%) 표가 보인다. 이 문구 중 구간표(1,200만원 이하 0.6% 등)는 2014년 개정 설명으로 구세대 안내문이다. 실제 계산은 국세 산출세액의 10%로 처리되는 것으로 추정한다(C000, C001 기대값과 일치).
- 주식 계열: 대주주 1년 미만 3%, 중소기업 1%, 그 외 2%.
- 별도 입력: "지방소득세 가산세는 따로 입력" 안내.

### 3.1 C000 (상가 토지+건물 일괄 양도, 5년 3개월, 장특 10%, 기본세율)

1. 자산 L1(토지), B1(건물)을 자산 폼에 각각 입력 → 각 폼 계산이 `TIncome.Exec`: 양도가액·취득가액·필요경비 → 양도차익. 기대값(케이스 yaml): L1 176,200,000, B1 41,300,000, 합 217,500,000.

### 3.2 C001 (1세대1주택 고가주택, 양도 15억, 보유·거주 7년)

## 4. 구조상 특징 (재구현 시 유의가 아니라 이해용)

- 양도박사는 자산 1건 단위로 양도소득금액까지 계산해 JASAN100에 저장하고, 세액은 양도인 단위로 다시 모아 계산한다. 즉 두 단계(자산 폼, 세액계산 화면)이며, 세액 화면은 저장된 소득금액을 읽는다. 편집허용 후 "세액재계산"을 눌러야 최신화된다.
- 세율은 연도별 하드코딩(분기 문자열)과 Firebird 쪽 값을 섞어 쓴다. 장특 비율은 배열(정적 데이터), 고가주택 기준과 누진세율은 코드 상수다.
- 계산근거 문구는 코드에 하드코딩된 서식이며, 같은 계산식이 로그(TCalLog)와 값 계산에 이중으로 구현되어 있다.
